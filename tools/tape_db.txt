# Tape hint database: what to type for tapes whose next steps are not on the tape (rtl/tape_hint.sv).
# tools/tape_db.py turns it into rtl/tape_db.svh (the table the core uses) and into test scripts.
#
# title: NAME [pcg] [mk2|mk2n] [fails]   one title; pcg / mk2 / mk2n: needs the PCG-8100 / the PC-8001mkII
#                              (N80 mode / Mode N); fails: does not run on any PC-8001 model in CSCP either
#                              (BASIC 1.1 to 1.3, Disk BASIC: Syntax error / Disk BASIC Feature, most likely
#                              PC-8801 listings), the lines are what its notes say
# tape: FILE                   one of the title's tapes, in the order they are used (path under the pack)
#   Z: STEP ; STEP ...         what to type once the tape has played past its Z-th file (0 = at its start).
#                              A zone not listed keeps the core's own hint (CLOAD"name" / MON L at the start,
#                              RUN after a BASIC program with nothing after it); "-" shows nothing.
# play: KEYS                   test only: keys that start the game once the last step is typed
# wait: N                      test only: N more frames before the screenshots (a program that loads more itself)
# Keys as in sim --type / CSCP --type: \n = Return, {CTRL}B = Ctrl+B.
# The hint shows the steps of a zone on one line when they fit ("TYPE MON ↵ L ↵"), else one after another,
# each until its Returns (or its Ctrl+B) have been pressed.
# Sources: the readme / START.txt beside each tape (PC-8801 notes say MON R and load"cas:, which on the
# PC-8001 are MON L and CLOAD).
